# Cpp_Programming

A collection of C++ programs for learning and practice, starting from the basics.

## Programs

| File | Description |
|------|-------------|
| `First.cpp` | First C++ program: basic structure and output |
| `Datatype.cpp` | Demonstrates C++ data types |

## Roadmap
- [ ] Basics (first program, data types)
- [ ] Operators
- [ ] Control statements (if, switch, loops)
- [ ] Arrays and strings
- [ ] Functions and pointers
- [ ] Classes and objects (OOP)
- [ ] STL (vector, map, set)

## Requirements
- G++ compiler (GCC)
- Any editor (e.g. VS Code)

## How to Run
```bash
git clone https://github.com/hariomtirkamate/Cpp_Programming.git
cd Cpp_Programming
g++ First.cpp -o first
./first          # Windows: first.exe
```

To run the other program, replace the file name, for example `g++ Datatype.cpp -o datatype`.
